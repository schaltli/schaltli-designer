# Card grid

Spec for module `card-grid` of docs/2026-11-03-cards.md, drafted 2026-11-03.
**Status: approved by the user on 2026-11-03; built 2026-11-03 (tasks/card-grid-todo.md).**

## Objective

CamperUI's Home and Power screens are grids of cards: two or three equal
columns across the screen, an even gap between, every card in a row as tall
as the others. A table put together by snapping (docs/2026-10-09-snap-
tables.md) is almost that, since a card is a free area and a free area sits in
a cell. Three things are missing:

- The gap between cells is a fixed 1.5 mm; cards want more air.
- A card snapped into a cell keeps its own size, so cards in a row end at
  different heights unless each is set to Stretch by hand.
- A table is as wide as its content; there is no «two equal columns across
  the screen».

Success looks like: four cards snapped together make a 2 × 2 grid with
equal columns across the width the table is given, every card filling its
cell, the gap set on the table; a project saved before this opens exactly
as it was.

**Decisions** (the user, 2026-11-03):

- **Gap per table**, a field on the table, default 1.5 mm as today, for
  every table, not only one of cards.
- **A card snapped into a cell fills it:** Horizontal and Vertical Stretch,
  set when it lands; changeable under Cell. A plain free area as today.
- **Table width and equal columns:** a table may be given a width, and its
  columns may be made equal, sharing that width.

## Behaviour

- **Table section** (property panel, «Table»):
  - **Gap**, mm, 0 to 10, default 1.5. Between columns and between rows.
  - **Width**, mm, empty by default: as wide as its content, as today. Set,
    the table is at least that wide; the last column takes what is left - as
    a table in a switcher's panel is stretched today.
  - **Equal columns**, a toggle: every column as wide as the widest needs;
    with a Width, every column an equal share of it. Never narrower than
    what a column holds: where a share is too small for one column, all are
    as wide as the widest, and the table is wider than its Width.
  - A column dragged to a size by hand (its line) keeps it; Equal columns
    shares out only among the others. «Auto sizes» clears hand sizes, not
    Gap, Width or Equal columns.
- **A card into a cell:** dropped or placed into a cell, a free area with a
  Look (docs/2026-11-03-card.md) gets `cell.anchor` `{ x: "stretch", y:
  "stretch" }` unless it already has an anchor there. Rows are as tall as
  their tallest card, so the others stretch to it.
- **Dock and anchors inside** a stretched card work as in any free area:
  its heading stays at the top, its table fills the rest.
- **On the device** nothing changes: a table is dissolved into placed
  objects.

## Not in scope

- Rows of equal height across the table (each row is as tall as its
  tallest card; a row height can be dragged by hand as today).
- A width in percent of the screen, or a table that follows the screen's
  width (a table has a width in mm; set it to the screen's).
- Clipping to round corners (`card-clip`), blocks as cards (`card-blocks`).

## Data model

```ts
// on a table put together by snapping (properties.grid = 1)
properties.gapMm?: number        // default 1.5 (SNAP_GAP_MM)
properties.widthMm?: number      // unset: as wide as its content
properties.equalColumns?: true
```

Absent means today's table; no migration.

## Code

- `lib/snap-table.ts` `measure`: the gap from `gapMm`; equal columns and the
  width applied after the natural and hand sizes, before spans are fitted.
  `arrangeSnapTable`'s `stretchTo` and `widthMm` combine as the larger.
- `lib/snap-table.ts` `placeInCell` / `applySnapDrop`: a free area with a
  look gets the stretch anchor.
- `lib/dock.ts`: the gap between docked objects stays `SNAP_GAP_MM`.
- `components/property-panel/snap-table-properties.tsx`: Gap, Width, Equal
  columns.

## Testing

- `e2e/card-grid.spec.ts` (new, model): gap; width with the last column
  taking the rest; equal columns with and without a width; a hand-sized
  column kept; content wider than its share widens the table; a card
  dropped into a cell stretched, a plain free area not; a table without the
  new properties lays out to the same pixels as before; laying out twice
  changes nothing.

  section; four cards snapped into a 2 × 2 grid, equal, filling their cells;
  one Ctrl+Z per change.
- `e2e/snap-table-model.spec.ts`, `e2e/snap-table-canvas.spec.ts`,
  `e2e/bausteine.spec.ts` unchanged and green: tables without the new
  properties are today's.

## Boundaries

- **Always:** a table without the new properties exactly as today;
  designer-only; `test:quick` per change; handbook in the same work.
- **Ask first:** changing the default gap; equal row heights.
- **Never:** a device change.

## Success criteria

- [x] Gap on a table changes the space between its columns and rows
- [x] Width and Equal columns make equal columns across a width; content
      never squeezed
- [x] A card snapped into a cell fills it; a plain free area does not
- [x] Four cards make a 2 × 2 grid of equal cards across the width given
- [x] Old tables unchanged (pixel test)
- [x] Handbook updated; `test:quick` green apart from known load failures
